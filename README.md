# SYSTM Дела — сборки для macOS

Задачи и планы: входящие, сегодня, предстоящее, проекты. Данные лежат на вашем Mac в обычных файлах, облака нет. Здесь только готовые версии, последняя — в [Releases](https://github.com/alleyesonmemfk/systm-dela/releases/latest).

## Установка (один раз)

1. Скачайте `SYSTM-Dela_<версия>_universal.dmg` из [последнего релиза](https://github.com/alleyesonmemfk/systm-dela/releases/latest) и перетащите «SYSTM Дела» в «Программы».
2. Первый запуск: macOS скажет, что не может проверить разработчика. Откройте «Системные настройки → Конфиденциальность и безопасность» и внизу нажмите «Всё равно открыть».
3. На экране приветствия нажмите «Начать» — данные будут в «Документы / SYSTM Дела».

Дальше приложение обновляется само: при запуске оно проверяет новую версию и предлагает «Обновить» — скачивает её, сверяет подпись и перезапускается. Данные остаются в своей папке.
